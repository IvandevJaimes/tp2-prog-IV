## practica de GIT y GITHUB

Este repositorio a sido creado como una practica para aprender a gestionar
proyectos en git y github utilizando ramas para resolver o realizar
modificaciones del proyecto

## ESTRUCTURA DE RAMAS Y TAREAS

Para este ejercicio, el repositorio cuenta con una rama principal (main) una (dev)
y tres ramas individuales por cada integrante del proyecto para que se pueda trabajar 
en distintos implementos o modificaciones, que luego de ser evaluadas y/o corregidas
se integraran a la rama principal
