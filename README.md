## practica de GIT y GITHUB

Este repositorio a sido creado como una practica para aprender a gestionar
proyectos en git y github utilizando ramas para resolver o realizar
modificaciones del proyecto

## ESTRUCTURA DE RAMAS Y TAREAS

Para este ejercicio, el repositorio cuenta con una rama principal (main) una (dev)
y tres ramas individuales por cada integrante del proyecto para que se pueda trabajar 
en distintos implementos o modificaciones, que luego de ser evaluadas y/o corregidas
se integraran a la rama principal

## APLICACIÓN DE LAS 5 REGLAS DE SEO DE GOOGLE

En este ejercicio apliqué algunas reglas básicas de SEO en el HTML de la página para que Google pueda entender mejor su contenido.

Primero agregué un título claro para identificar de qué trata la página y una descripción para explicar brevemente el contenido.

También utilicé las etiquetas h1, h2 y h3 para organizar correctamente la información y darle una estructura más clara.

Además, utilicé palabras relacionadas con la cafetería, como café, cafetería, productos artesanales y menú, para indicar el tema principal de la página.

Por último, agregué el atributo alt en las imágenes para describir su contenido y facilitar que los buscadores puedan interpretarlas.
